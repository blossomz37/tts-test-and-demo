What this round tells us

01 · Cost

Free really was free.

Flux and Fish returned audio at $0. Kokoro was the cheapest paid call, at $0.00114 for this passage.

02 · Routing

The provider changes the price.

Kokoro and Orpheus both routed to Together. DeepInfra listed lower rates, but these requests used default routing.

03 · Usage

Tokens are not characters.

Gemini billed 58 native input tokens and 539 output audio tokens. The other paid calls matched character pricing.

Method, limits & sources

All eight recordings use the exact same passage. Each request supplied a model, a voice, the text, and an audio format. No speed, style, or routing override was sent. Every response passed a full audio decode check. Audio quality and word-for-word completeness have not been rated.

OpenRouter reported no separate generation-time value for any call. Costs are measured inference charges, excluding account funding fees. Prices and free-model availability can change.

Word timestamps were produced locally with stable-ts and Whisper base.en, aligning the supplied passage to each recording. These are approximate machine alignments, not provider timestamps or proof that every word was spoken. The audio and text are unchanged.

All recordings, timing data, and fonts are bundled. Playback makes no model calls and needs no API key. The request and billing links contain the sample evidence; account identifiers have been omitted from the shared receipt extracts.
